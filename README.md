# Desafío Tabla Periódica 🧪⚛️

Juego interactivo educativo para aprender y memorizar los símbolos químicos y nombres de los elementos de la tabla periódica.

## Características
- **Modo Símbolo ➔ Nombre**: Identifica el nombre a partir del símbolo químico.
- **Modo Nombre ➔ Símbolo**: Identifica el símbolo químico a partir del nombre del elemento.
- **Modo Mixto**: Desafío variado al azar.
- **Biblioteca de Exploración**: Buscador por número atómico, nombre o familia química.
- **Efectos sonoros y racha**: Sistema de puntuación con multiplicador de racha.

Desarrollado para fines educativos.
